# T7 decide、answer、guide

## 要旨

- 演者の一言が型に入り、LLM を呼ばずに札が変わるようになった（見せ場の 3・4）。`netacho reread` で弟子役に読み直させられる
- この経路は API が要らないので、認証が無くてもテストで確かめられた
- 判断をお願いしたいことは 0 件

## 何を狙って、どういう順で作ったか

plan の判断で「見せ場の 3・4 は外部に依存しないので、どの場合も残す」とされている経路。Claude を呼ばない経路を意図して残したことが、審査の「Claude の活用」で見せる点になる。

## 到達点

| 誰が | 何をする | 結果 |
| --- | --- | --- |
| 演者 | 候補を見て一言。`netacho decide` | 言葉がそのまま型に入る（`edited_by: performer`） |
| スクリプト | `netacho guide` | 承認済みの staging を場面順に写す。LLM の呼び出し 0 回 |
| 演者 | 弟子役の質問に `netacho answer` | 型に一行入り、指摘が解決になる。札には出ない |
| 弟子役 | `netacho reread` | 演者の判断と理由を読む。答え済みの所は聞き直さない |

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| LLM 0 回のテストは `anthropic` を読めない状態の別プロセスで行う | 呼び出しを数えるより強い。経路そのものが無いことを確かめられる |
| `answer` と `reread` は札を作り直す | 指摘で止まった札が古いまま画面に残るのを防ぐ |
| 同じ候補への 2 回目の `decide` は止める | 撮影の場で 2 回打っても札が重ならない |
| `answer` は途中で落ちてもやり直しで揃う | 書く順を決め、同じ言葉の項目は足さない |
