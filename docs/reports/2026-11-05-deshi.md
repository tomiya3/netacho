# T6 弟子役と仕分け

## 要旨

- 弟子役が `.md` だけを読んで指摘し、スクリプトが差し戻しと演者への質問に仕分ける流れができた。再生成は 1 回まで
- **実機の API は未実行**。「場面を指した具体的な指摘が出るか」「2 周目で減るか」は実機でしか分からない
- 判断をお願いしたいことは 1 件（API の認証）

## 何を狙って、どういう順で作ったか

見せ場の 5「弟子役が読むと判断が分かる」の土台。録音を読まない弟子役が演れない所が、そのまま伝承の抜けになる。

## 到達点

| 誰が | 何をする | 結果 |
| --- | --- | --- |
| 弟子役 | `.md` だけを読んで指摘する | 録音、反応、差し戻しの履歴を見ない |
| スクリプト | 場面の無い指摘を落とす | 落とした数が run.json に出る |
| スクリプト | 仕分ける | `ask_performer` は演者への質問、それ以外は構成作家役へ |
| 構成作家役 | 指摘の箇所だけ足すか直す | 再生成は 1 回まで |
| スクリプト | 2 周目と突き合わせる | 指摘の減りを数え、解決を決める |

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| 解決の条件を厳しくした | 解決は札の許可につながる。弟子役が 2 周目に言わなかっただけでは解決にしない。再生成がその場面を実際に変えたことまで見る |
| 演者の項目を指す指摘は `ask_performer` に回す | 構成作家役は演者の項目を変えない。差し戻しても直らず、札が永久に止まるため |
| 作り直しで同じ指摘を重ねない | 同じ所の未解決は 1 件のまま。前回の未解決も今回の差し戻しに入る |
