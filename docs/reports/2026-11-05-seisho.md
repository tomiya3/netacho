# 速記の清書

## 要旨

- 速記役を足し、聞き違いを直して話者を付けた台本の形の清書 `seisho.md` を作れるようにした。原文は必ず残す
- **実機は未実行**。どこまで読める台本になるかは、ユーザーの実行待ち
- 判断をお願いしたいことは 0 件

## 何を狙って、どういう順で作ったか

ユーザーの要望。Whisper の文字起こしは読みにくく、「文脈の読み」は Claude の強みなのに使えていなかった。審査の動画で、前提知識のない人にも価値が伝わる。

## 到達点

| 誰が | 何をする | 結果 |
| --- | --- | --- |
| 速記役 | 文字起こし、演目名、人物を読む | 区間ごとに話者と直した文を返す。反応は見ない |
| スクリプト | 全区間があるか、言い換えすぎていないかを確かめる | 抜けは原文で埋め、言い換えは原文に戻して数える |
| スクリプト | `seisho.md` を書く | 話者は「推定」、直した行には原文を添える。笑いの印はスクリプトが入れる |

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| 原文を必ず並べる | 「演者の言葉は書き換えない」を守る。清書は読み物で、演者の言葉の正本ではない |
| 言い換えの検査は文字列の近さで行う | 速記役の仕事は聞き違いの修正だけ。大きく変わった文は原文に戻す |
| 正本と札には入れない | 推定が型に混ざらないように |
| モデルは Sonnet | 文を写して直す仕事で、長い出力になるので費用を抑える |
