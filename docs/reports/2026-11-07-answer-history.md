# 答えを次の問いに活かす（#70）

## 要旨
- 問いを作る役（聞き役、ノート役）が、同じ演目で演者が答えた内容と、問いを捨てた理由を読んでから問うようになった
- 答えから問いの質が上がったかは、まだ測っていない。実データで答えが溜まってから見る
- 判断をお願いしたいことは 1 件

## 何を狙って、どういう順で作ったか
今は、答えた所を聞き直さないだけだった。演者に「教えるほど育つ」と説明していたが、答えの中身は次の問いに使われていなかった。説明と実装を合わせるため、問いを作る役に答えを渡した。答えが問いに事実として混ざる経路は、文脈なしレビューの指摘でスクリプトでも止めた。

## 到達点

| 誰が | 何をする | 何が起きる |
|---|---|---|
| 演者 | 問いに答える、または的外れとして捨てる | 今まで通り帳面に残る |
| 聞き役、ノート役 | 次の問いを作る | 同じ演目の答えと捨てた理由を、新しい順に 20 件まで読む |
| スクリプト | 返ってきた問いとノートを確かめる | 答えの言葉が 6 字以上続けて入っていたら落とす |

役に渡る塊の例（ダミーの高座）。設計どおり、答えのある問いだけが渡る。

```
# これまでのやり取り
[
 {
  "問い": "行列の見立てを演ろうとした。なぜ間を詰めるのかが書いていない。",
  "答え": "行列のところは間を詰めて次へ行く"
 }
]
```

## 主な判断と、その理由
- **未回答の問いは渡さない:** 答えの無い所を「受けなかった」と読ませないため
- **やり取りが無ければ入力を変えない:** 今までの結果と費用の控えを崩さないため
- **答えの混入はスクリプトでも止める:** 役への指示だけでは、答えを事実として問いに書くのを防げないため。言い換えは見ていない
- **1 つの文は 200 字で切り、切ったと書く:** 長い答えが並んでも費用が膨らまないようにするため。要約はしない
- **見せる物の境界を広げた:** 答えには型の一部や笑いの話が入ることがある。演者の言葉として許し、plan に書いた

## 数字（実測）

| 値 | 意味 |
|---|---|
| `make test` 944 件通過 | 偽の応答で確かめた範囲。問いの質は測っていない |
| 文脈なしレビューの指摘 5 件 | すべて反映 |

## 判断・用意をお願いしたいこと
1. 演者の答えが溜まったら、同じ高座で問いを作り直し、前の問いと読み比べる。無いと、答えが活きたかを言えない

## リスク

| リスク | 現状 | 対策 |
|---|---|---|
| 答えを言い換えて問いに混ぜる | 言い換えは検査していない | 実データの問いを読む（#70） |
| 答えに引っ張られて、同じ向きの問いばかりになる | 未確認 | 答えが溜まってから読み比べる |
