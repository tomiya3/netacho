# 同じ演目の 2 本を比べて、弟子が師匠に聞く

## 要旨

- 同じ演目の 2 本を台詞で揃えて比べ、変えた所と変えていない所を演者に問えるようにした
- 同じ録音を別に文字起こしした 2 本の検査で、タイミングの誤差は 0 件。本物の別の 2 本では、まだ測っていない
- 判断と用意をお願いしたいことは 2 件（マージの指示、同じ演目の録音 2 本）

## 何を狙って、どういう順で作ったか

落語は同じ噺を何度も高座にかけて磨く。1 本の分析より、変えた理由を本人に聞くほうが、演者にとって意味がある。Issue #47 でこれを中心に据えた。比較の軸は、ユーザーの指摘で、笑いの量からタイミングに変えた。

## 到達点

| 誰が | 何をする | 結果 |
| --- | --- | --- |
| 開発者 | `netacho compare` で 2 本を指定する | 台詞で揃え、種類ごとの所と問いを作る |
| 演者 | 「2 本の比べ」のタブを開く | 2 本の波と、比べた所を見る。2 本の録音をそれぞれ聞ける |
| 演者 | 質問のタブで答える | 今までと同じ経路で、言葉のまま型に残る |

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| 笑いの大きさを比べない | 録音の条件で変わる。来る所だけを比べる |
| 場面の ID に頼らず、清書の文字で揃える | 2 本目で ID が揃う保証が無い。文字なら直接比べられる |
| 清書どうしで比べる | 文字起こしどうしでは Whisper の誤りが差に見える |
| 間は VAD の無音から取る | 文字起こしの区間では、同じ録音でも切れ目で数秒ずれた |
| 片方に山が無ければ笑いを比べない | 未検出を反応なしと扱わない |
| 同じ録音の 2 本で検査した | 本当の差が 0 件と分かっている材料なので、誤差が測れる |

## 数字（実測）

同じ録音を別に文字起こしした 2 本の検査。片方は Sonnet の清書、片方は Opus の清書。

| 項目 | 値 | 意味 |
| --- | --- | --- |
| 同じ所（`kept`） | 9 件 | 笑いの所が正しく揃った |
| 来る所のずれ（`moved`） | 0 件 | 本当の差は 0 なので誤差も 0 |
| 片方だけ（`one_side`） | 0 件 | 同上 |
| 間の差（`ma`） | 0 件 | 直す前は 3 件 |
| 言葉の差（`words`） | 17 件 | 清書の違いによる偽物。直す前は 60 件 |
| 比較の時間 | 0.22 秒 | 7000 字どうし |
| 比較の時間（繰り返しの多いダミー） | 1.06 秒 | 1 万 6000 字どうし |
| テスト | 実行結果は PR 本文 | |
