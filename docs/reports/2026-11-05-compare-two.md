# 同じ演目の 2 本を比べて、弟子が師匠に聞く

## 要旨

- 同じ演目の 2 本の、どの台詞が同じくだりかを Claude が読み、スクリプトが確かめて、笑いと間の実測を付ける形にした
- 本物の 2 本（本番と稽古）で対応 100%、聞き役が笑いの所 38 件を読んで問い 5 件を書いた。同じ録音の検査では偽物の差が 0 件
- 判断をお願いしたいことは 2 件（問いの中身の確認、マージの指示）

## 何を狙って、どういう順で作ったか

落語は同じ噺を何度も高座にかけて磨く。1 本の分析より、変えた理由を本人に聞くほうが、演者にとって意味がある。比較の軸は、ユーザーの指摘で、笑いの量からタイミングに変えた。最初は清書の文字で揃えたが、本物の 2 本では 3% しか揃わず、対応を Claude が読む形に作り替えた。

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| 対応は Claude、事実はスクリプト | 同じくだりかは意味の判断。笑いと間は測れる事実なので役に作らせない |
| 行の対応も聞き役が読む | 割合の計算では場所がずれた（ユーザーの指摘） |
| 検査に落ちた問いは出さない | 場所の合わない問いを決まった文で埋めるより、少ないほうがよい |
| 役に笑いの位置を見せない | 結果から対応を逆算させない |
| 笑いの大きさを比べない | 録音の条件で変わる。来る所だけを比べる |
| 間は VAD の無音から取る | 文字起こしの区間では、同じ録音でも切れ目で数秒ずれた |
| 稽古は本番の笑いを軸に比べる | 客がいないので、笑いの有無を比べても意味が無い |
| 同じ録音の 2 本で検査した | 本当の差が 0 件と分かっている材料なので、偽物の差が測れる |
