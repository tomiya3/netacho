# T8 速記と netacho run

## 要旨

- 文字起こしに反応の印を入れた `sokki.md` が `netacho note` で出るようになった。`netacho run` で prep、build、note を一度に回せる
- 判断をお願いしたいことは 0 件

## 到達点

| 誰が | 何をする | 結果 |
| --- | --- | --- |
| スクリプト | 反応の位置に（笑い）（拍手）（反応）を入れる | LLM は使わない |
| 演者 | `sokki.md` を読む | 未校正と、印の位置が目安であることが先頭に出る |
| ユーザー | `netacho run` | prep、build、note を順に回す（引数の受け渡しをテストで確認。通しの実測はまだ） |

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| 印は反応が始まった時点で話していた区間、無ければ直前の区間の後ろに入れる | 笑いは直前の台詞の後に来る。文の途中には入れない |
| 位置は目安と明記する | AST の窓は 5 秒あり、秒単位の位置は言えない |
| `netacho run` は先に認証を確かめる | 長い文字起こしの後で落ちないように。`count_tokens` は課金されない |
| 速記はノート役より先に書く | LLM が要らないので、ノート役が落ちても残る |
