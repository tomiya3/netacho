# 語の表と、枕の話題の比較

## 要旨

- 本番どうしの 2 本を実物で比べ、清書と枕の扱いの弱さが分かったので直しました
- 実物のやり直しで、教えていない固有の語が高座全体で直り、会場に合わせた言い換えの所が 1 番目の問いになりました
- 判断をお願いしたいことは 2 件です

## 何を狙って、どういう順で作ったか

比較の見せ場は「同じ演目の 2 本で、何を変え、何を変えていないか」です。本番どうしの比較は未確認でした。実物で流すと、対応の割合は 65% で、問いの 3 件が噺の外（枕と、噺の前の説明）に寄りました。枕の違いが比較を埋めていて、良い所は問いに入りませんでした。原因を調べ、清書、枕、聞き役の順に直しました。

## 到達点

| 誰が | 何ができるようになったか |
| --- | --- |
| 演者 | 枕を話題の表で見られる。噺の下地の話題に印が付く |
| 演者 | 高座全体で固有の語の表記が揃った清書を読める |
| 演者 | 語を知っていれば `netacho seisho --terms` で渡せる |
| 聞き役 | 笑いのあった所を上限なしで全部読む |

## 主な判断と、その理由

| 判断 | 理由 |
| --- | --- |
| 清書の前に全文を読む語の表役を足す | 清書は区間ごとの別の呼び出しで、ある塊で分かった語が別の塊に届かなかった。塊の順に引き継ぐより、全文を先に読むほうが、後ろにある手がかりも使える |
| 語の表は手がかりとし、置き換えない | 同じ字でも普通の語の所があるため。文脈の判断は速記役に任せる。実物で普通の語は直されなかった |
| 枕の行どうしを比べない | 枕は会ごとに変わる。もう 1 本に無いのは当たり前で、「足した言葉」と呼べない |
| 枕の話題は役の読み、位置と山の数は実測 | 事実はスクリプト、意味の判断は Claude の約束どおり |
| 笑いの所の上限を外す | 長い枕で候補が増え、読ませない所が出た。費用は `budget.py` が止める |
| 枕の問いは 1 問まで | 比べる軸は噺。聞いてよい所は枕の笑いに絞る |
| 実物のやり直しでは語を教えない | 語の表だけでどこまで直るかを見るため。ユーザーの判断で、直らなくても渡さないと決めた |

## 数字（実測）

同じ 2 本を、この変更の前後で比べました。録音は repo に含めません。

| 項目 | 変更前 | 変更後 | 意味 |
| --- | --- | --- | --- |
| 対応の付いた割合 | 65%（枕を含む） | 100%（枕を除く） | 測り方も変えたので、値の差は改善幅ではない |
| 聞き役が読めなかった所 | 25 件 | 0 件 | 上限を外した |
| 問い 5 件のうち噺の中 | 2 件 | 5 件 | 「足したのか」の問いは 2 件から 1 件に減った |
| 枕の問い | 2 件 | 0 件 | 上限は 1 問。噺の問いで 5 件埋まった |
| 語の表 | － | 66 語、落とした語 0 | 語の正しさは全部は確かめていない |
| 枕の話題 | － | 37 件、うち下地 4 件 | 役の読み |
| 費用 | － | $2.47（語の表 $0.13） | 清書と比較のやり直し。累計 $14.34 |

## 判断をお願いしたいこと

1. 枕の問いを、噺の問いと競わせるか、1 問は必ず入れるか。無いと枕の問いは 0 問の回が出ます
2. 問いにならなかった所の一覧を画面に残すか。行を確かめるのは聞き役が選んだ所だけなので、台詞の組がずれて見える所があります

## リスク

| リスク | 現状 | 対策 |
| --- | --- | --- |
| 語の表の語が間違っている | 実物 66 語の全部は確かめていない | 清書は原文を並べて残す。正本と札には入れない |
| 笑いの `moved` が本物か分からない | 台詞の無い所は文字が当てにならない | 耳で確かめる |
| 同じ録音の検査 | 枕の変更後は未実施 | API が要る。次の比較の見直しのときに流す |
| 枕の問いの上限は聞き役の返答の後で効く | 8 件の枠が枕で減る場合がある | 実物では枕は 8 番目の 1 件だけ。見送り |
